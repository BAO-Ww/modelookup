# 型号查询 · 隆阳电器（公布版）

把金山文档在线表 + 用友 ERP 变成一台**独立窗口运行的桌面软件**：双击就开（自带 WebView2 内核，**不弹浏览器**），
输型号或品类就能看到清理价、实时库存（含在哪个仓）、发货区域、货来源、补贴、闲鱼上架情况，
美的/容声另带官网参考价，内置闲鱼定价计算器（自动算出库奖励）与「已发布」标记（云端同步）。

数据源（**价格看金山、库存看用友**）：

| --- | --- | --- | --- |
| ① | 金山在线表「公布版-滞销样机清理明细」 | 清理价 + 清理库存口径 | 分享码 `ch7gwGTP9De4`（fileId `548020345856`），只读 `10月滞销清理明细` + `10月样机清理明细` 两个 sheet（**别的 sheet 一律不读**） |
| ② | 金山在线表「2026年10月价格表-LYDF-共享」 | 全新机报价 + 发货 + 补贴 + 闲鱼 | 分享码 `cficbK9Drrdp`，只读 `型号价格表（只看这个）` + `美的` 两个 sheet |

| ④ | 品牌官网商城（构建期抓好随包带） | 官网参考价 + 型号详情页直链 | 美的商城 238 个 + 海信商城容声 47 个；另有官网机型库匹配出 **760+ 个型号的详情页直链** |

仓库明细走用友实时（这台货**现在**在哪个仓、各仓还剩多少）。
官网价抓取脚本：`_midea_fetch.py`（断点续传）、`_ronshen_fetch.py`（浏览器内分块跑，绕 WAF）。月度更新时重跑一遍即可刷新。

## 软件里能做什么

**窗口形态**：原生标题栏 + 原生菜单（数据 / 帮助），没有地址栏、没有标签页、没有浏览器外壳。

## 更新数据

价格和库存**每小时自动静默更新**（首次使用需手动点一次），更新成功后侧栏显示「价格 月-日 时:分 · 库存 月-日 时:分」，
页面**无感换新数据**——不用重开软件，也不丢当前筛选。也可以手动：

1. **点「↻ 从金山文档更新数据」** —— 拉两个价格表重建
   - 打开在线表页面后先**静默重试约 20 秒**：该表是公开分享的，匿名会话往往就能拿到下载直链，用户什么都不用做。
   - 拿不到才弹出「登录金山文档」窗口让人扫码，登录成功后**自动继续、不用点任何按钮**。
   - 价格表的 fileId 不是硬编码的，而是**打开分享页后从它自己发出的请求里反查**再缓存到本地，分享码换了也不用改代码。
   - 价格表这次没拉成功时**不会阻断整体更新**，沿用上一次的价格表数据。
   - 登录态留在本机 WebView2 配置里，之后都是静默更新（CAS 会话级：软件重启后首次更新可能要重登一次）。
2. **点「更新实时库存」** —— 从**用友 YonSuite ERP** 拉全量库存按仓聚合（需要用友登录，同进程内复用）。
3. **点「📂 用本地 Excel 更新」** —— 传 xlsx，程序按表头**自动识别是哪个表**并归位（在线表登不上时的兜底）。

**核心取数技巧**：不搬运 cookie，而是在**已经处于 `www.kdocs.cn` 域的 WebView2 窗口里跑同步 XHR**
`GET /api/v3/office/file/<fileId>/download`，同源自动带登录态，拿到 `download_url` 后
**免 cookie 直接下载**。这样换任何一台电脑、装完就能用。

## 让 GitHub 自动打包（推荐，正式出包走这条路）

推上去之后**不用本机编译**，GitHub Actions 在 Windows runner 上自动：
装 Python → 装依赖 → PyInstaller 打包 → 跑成品自检 → 装 Inno Setup → 编译安装包 → 发 Release。

工作流：`.github/workflows/build-installer.yml`

| 触发方式 | 结果 |
| --- | --- |
| 手动点 **Run workflow** 并填版本号（如 `v2.2`） | 构建 + **发 Release** |
| 推 `v*` 标签 | 构建 + **发 Release** |
| 推 `main` | 只构建、上传 Artifact（**不发 Release**），用来验证能编过 |

发出来的 Release 里会有两个附件：`ModelLookup-Setup-X.Y.exe`（安装包，就是「型号查询」）和 `ModelLookup.exe`（绿色版）。

> ⚠ 必须记住的坑：
> 1. `actions/setup-python` 的 `cache: pip` **必须配 `cache-dependency-path: requirements-build.txt`**，否则它去找不存在的 `requirements.txt` 会直接挂。
> 2. runner 控制台是 **cp1252**，Python 往 stdout 打中文会 `UnicodeEncodeError`。工作流里设了 `PYTHONIOENCODING=utf-8` / `PYTHONUTF8=1`，整理产物的那一步也交给 `.github/scripts/stage.py` 做。
> 3. **Release 附件的文件名必须纯 ASCII**：GitHub 会把 asset 名里的中文「消毒」掉（实测 `型号查询-安装包-v2.1.exe` 上传后变成 `-.-v2.1.exe`），所以进 Release 的文件统一用英文名。
> 4. **自检必须用 Python 跑**：exe 是 GUI 子系统（`console=False`），PowerShell 用 `&` 调用它**不会等进程结束**，立刻返回后读 `exe_check.log` 会报「文件不存在」。用 `.github/scripts/check_exe.py`（`subprocess.run` 会等）并校验 ASCII 哨兵 `RESULT: PASS`。

## 打包 / 启动踩过的坑（都已在代码里注释）

- **启动慢的锅不在页面大小，在「连端口探活」**。原先是「逐个 urlopen `/api/ping` 看自己有没有在跑」，
  而本机（以及不少装了安全软件的机器）连 `127.0.0.1` 的**未监听端口不会立刻回 ECONNREFUSED**，
  而是一路等到超时 —— 实测 **0.6 秒/个 × 8 个端口 = 4.8 秒**，全压在启动路径上。
  现在改成 **`CreateMutexW` 命名互斥量**判单实例（瞬时），端口号写 `port.txt` 供第二个实例 `activate` 用。
  **实测 5.86 秒 → 0.92 秒。**
- 页面**不再内联数据**：`bootstrap()` 只写模板（56KB），数据走 `/api/data`（0.40MB）、
  图片走 `/img/<core>`（真正按需，看得见才解码）。自检里有一条「页面 < 400KB」的哨兵防回归。
- `openpyxl` / `webview` 必须**模块顶层 import**。放函数体内会被 PyInstaller 判成「延迟/可选」而不打包，spec 的 `hiddenimports` 也救不回来。
- **千万别 excludes `webview.platforms.win32`**：winforms 顶层就 `from webview.platforms import win32`，排掉它会让 `import webview.platforms.winforms` 失败，而 pywebview 会**误导性地报「You must have pythonnet installed」**。自检里专门留了一条 winforms 导入探针防回归。
- Inno 的 `PrivilegesRequiredOverridesAllowed=dialog` 会让安装包尝试提权，在受限环境里会**静默退出、什么都不装**。免管理员安装就别开它。
- `webview.create_window()` 必须在 `webview.start()` **之前**调用 —— 所以扫码登录窗口是启动时就建好、`hidden=True` 藏着，需要时才 `show()`。
- WebView2 是独立进程合成的，`PrintWindow` 抓不到内容；GUI 冒烟截图必须抓**屏幕区域**。
- `core_of()` 截掉中文后**必须 rstrip `(-_/+.,、，`**，否则 `BCD-550WGCFDM4WHU1(棕)` 会留下拖尾 `(`，跟图库 key 对不上（前端 `coreOf` 是同一套逻辑，改一处要同步另一处）。
- 表头解析有坑：「价格 含税」中间带空格、「利润」那列真名是「除去提货价与平台扣点后利润，考虑是否可做活动」、
  表头行里混着日期序列号占位 —— 所以列名匹配做了**去空格归一 + 精确优先 + 包含兜底**，占位格从下一行同列补名。
- **「全国可发」这一列不能按字面读**。它回答的是「能不能发到深惠广莞以外」，不是「能不能发」——
  所有型号都能发深圳/惠州/广州/东莞（表里空白的、写「不可以」的、写进货年限的，说的都是这个意思）。
  所以卡片上绿色的「深惠广莞」永远在，另外写了口径的原文照显。
  语义码 **1=可发全国 / 2=要问过才知道 / 3=只发深惠广莞**；
  `app/main.py` 的 `NAT_CAT` 与 `parse_kdocs.py` 的 `NAT_CAT` 必须保持一致，模板里的 `NAT_EXTRA` 也要对上。

## 已知限制

- 少数型号没有官方整机图（配件、门体、已停产渠道专供款），页面显示「＋ 补图」占位（当前 1337/1640 = 81.5%）。
- **官网价覆盖 285/663（43%）**：官方商城只挂在售零售机，线下专供机 / 工程机 / 已下架老款查不到，
  这部分卡片只显示表里的拿货价（不编造）。月度重跑 `_midea_fetch.py` / `_ronshen_fetch.py` 可刷新。
- 价格表里「利润 / 补贴可赚 / 用户补贴」是**表内公式算出来的**，闲鱼价没填时会算出 0 或负数；
  界面只在 > 0（利润：且有闲鱼价）时显示，避免误导。
- **库存是更新那一刻的用友实时快照**（自动每小时、手动随时）；两次更新之间卖掉的货不会立刻反映，以 ERP 当下数据为准。
- 在线表文档标题仍是「公布版-**8**月份…」，但里面的 sheet 是 `10月滞销清理明细` / `10月样机清理明细`，数据确实是 10 月的（文档没改名而已）。
