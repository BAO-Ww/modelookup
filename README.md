# 型号查询 · 隆阳电器

把「金山文档 · 公布版-滞销样机清理明细」在线表变成一台**离线可查的型号工具**：输入型号或品类就能看到清理价、库存、仓库分布、全国可发口径，并内置闲鱼定价计算器与「已发布」标记。

## 交付物

- `型号查询.exe` —— 单文件桌面工具（Windows）
  - 双击即开：内部起本地服务 + 默认浏览器打开查询页，数据已内嵌，秒开
  - 页面上「↻ 从金山文档更新数据」：用保存的登录态拉最新在线表并重建页面
  - 也可以把从金山文档下载的 `.xlsx` 直接拖到 exe 图标上重建
  - 小窗口里有三个按钮：打开查询页 / 从金山文档更新 / 用本地 Excel 更新
- `型号查询-公布版.html` —— 同一份查询页的单文件离线版（可直接双击打开、发给别人）

## 查询页能做什么

| 能力 | 说明 |
| --- | --- |
| 型号检索 | 支持片段、大小写、全角半角、空格、颜色后缀（`BCD-550WGCFDM4WHU1(棕)` 也能命中本体） |
| 品类检索 | 直接搜「冰箱」「洗衣机」，或点品类标签 |
| 品牌 / 品类筛选 | 卡萨帝 / 海尔 / 统帅 / 科沃斯 … |
| 清理方式 | 全部 / 只滞销 / 只样机 |
| 只看有货 · 只看可发全国 · 只看未发布 | 三个快捷开关 |
| 清理价区间 | 自己输入 min~max，按该型号**最低清理价**筛 |
| 全国可发 | 保留原始业务口径并上色：可发（绿）/ 不可发（灰）/ 待确认（黄） |
| 库存 | 可用量、现存量、在库合计 + 「仓库明细」展开到各仓 |
| 闲鱼定价计算器 | 输入你的定价 → 平台费 1.6% → 实挣（定价 − 定价×1.6% − 成本），可切换用滞销价还是样机价当成本 |
| 标记已发布 | 防重复上架，记录存在本机浏览器 |
| 我的定价自动保存 | 输入过的闲鱼价按型号记住 |
| 补图闭环 | 缺图的卡片点「＋ 补图」贴本地图片（自动缩到 240px、透明底补白），可「导出我补的图」交回重烤进页面 |

> 「标记已发布」「我的定价」「我补的图」都只存在你这台电脑的浏览器里，换电脑或换文件名打开不共享。

## 数据来源

- 在线表：<https://www.kdocs.cn/l/ch7gwGTP9De4>（公布版-滞销样机清理明细）
- 取数方式：`GET /api/v3/office/file/548020345856/download` → 直链 xlsx（需要金山文档登录态）
- 图源：海尔 / 卡萨帝官网机型库（CMS）+ 海尔商城，透明图统一合成白底

## 目录结构

```
modelookup/
├─ app/                      # exe 源码
│  ├─ main.py                # 解析 + 渲染 + 一键更新 + 本地服务 + GUI
│  ├─ ModelLookup.spec       # PyInstaller 配置
│  ├─ make_icon.py           # 程序化生成 icon.ico（≤128 严格 BMP 条目）
│  └─ assets/                # 打包进 exe 的资源
│     ├─ template.html       # 查询页模板（唯一前端源）
│     ├─ payload.json        # 初始数据（型号 + 图）
│     ├─ images_cache.json   # 图库（更新时按型号重新匹配）
│     ├─ cookies.json        # 金山文档登录态（不入库，见 .gitignore）
│     └─ icon.ico
├─ build.py                  # 旧的本地价格表流水线（保留备查）
├─ parse_kdocs.py            # 在线表 xlsx → payload
├─ build_kdocs.py            # payload + 模板 → 单文件 HTML
├─ fetch_images_kdocs.py     # 官网机型库补图
├─ fetch_missing.py          # 海尔商城补图
├─ template_kdocs.html       # 单文件 HTML 用的模板
└─ 重建型号查询.bat           # 换月时把新 xlsx 拖上去即可
```

## 自己重建

```bash
# 1) 在线表 xlsx → 数据
python parse_kdocs.py "D:\...\公布版-滞销样机清理明细-YYYY-MM-DD.xlsx"

# 2) 补图（可选）
python fetch_images_kdocs.py      # 官网机型库
python fetch_missing.py           # 海尔商城

# 3) 生成单文件 HTML
python build_kdocs.py

# 4) 打包 exe
cd app
python -m PyInstaller --noconfirm --distpath dist_v1 --workpath build_v1 ModelLookup.spec
```

依赖：`openpyxl`（解析）、`Pillow`（仅供 make_icon.py 生成图标，exe 本身不需要）。

## 已知限制

- 金山文档登录态会过期。过期后「从金山文档更新」会提示失败，此时用「用本地 Excel 更新」（在浏览器打开在线表 → 下载 xlsx → 拖到 exe 上）即可。
- 少数型号没有官方整机图（配件、门体、已停产渠道专供款），页面会显示「＋ 补图」占位。
- 清理价 / 库存取自在线表快照，实际以 ERP 实时数据为准。
