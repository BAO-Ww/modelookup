型号查询 · 隆阳电器（公布版） v2.2
========================================

这是一个独立窗口运行的小软件，双击就开，不弹浏览器。


一、怎么用
----------
1. 桌面/开始菜单 双击「型号查询」→ 弹出软件窗口（自带内核，没有地址栏）。
   **不到 1 秒就出来**（上一版要等 5~6 秒，慢在启动时的一个端口探测上，已经修掉）。
2. 打开后**不会铺一列卡片**（这是查找工具，不是浏览工具）。直接敲：
   · 型号（可以只输片段，比如 BCD-501 或 501WGHTD）
   · 或者品类，比如 冰箱 / 洗衣机 / 热水器 / 厨电
   · 也可以点页面上的示例词、或点品牌 / 品类标签
3. 标签筛选：品牌 / 品类 / 清理方式 / 只看有货 / 只看可发全国 / 只看未发布
4. 价格区间：填最低价~最高价，按型号最低清理价筛。


二、卡片上都有些什么
--------------------
清理价一排：滞销清理价 / 样机清理价 / 零售指导价 / 滞销出库奖励 / 样机出库奖励 / 清理数量
全新机报价一排：价格含税 / 滞销价格 / 样机价格
库存：**正品可用 · 样机可用** 两个口径。
      （公布版的「滞销可用量」和价格表的「正品可用库存」其实是同一批货，已经合并了，
        不会再并排显示两个一样的数字让你以为有两批。）
发货：发货区域 · 货来源。表里写「可发全国加运费100 / 报备可发全国加运费100 /
      询问是否可发全国加运费100」的，统一显示成「… · 加100运费」，
      鼠标放上去能看到表格里原来写的字。
发往：**所有型号都能发深圳/惠州/广州/东莞 · 包邮**（那个绿色标签永远在）；
      表里另外写了口径的，原文照显上色 ——
        报备可发全国 / 可以          → 蓝色（报备后能发全国，要看地址）
        找品类报备确认 / 一单一询…    → 橙色（要问过才知道）
        进货大于3年… / 进货小于3年…  → 灰色（实际还是只发深惠广莞）
补贴：补贴 69 码 · 补贴最高价格 · 补贴可赚 · 用户补贴金额
闲鱼：闲鱼商品 ID · 闲鱼价格 · 利润
（「补贴可赚 / 用户补贴 / 利润」是表里公式算的，没填闲鱼价时会算出 0 或负数，
  那不是真的可赚，软件只在大于 0 时才显示，免得误导。）


三、发闲鱼时用得到的
--------------------
· 「标记已发布」：发过闲鱼的点一下，卡片变灰。下次打开还在（存在本机）。
· 「闲鱼定价」：输入你打算卖的价，自动算能挣多少。
    算法：你的定价 − 定价×1.6%（闲鱼平台费）− 含税成本 = 到手利润
    成本可以在「滞销价 / 样机价」之间切换。
· 「复制」：一键把型号信息复制走。
· 缺图的卡片上有「＋ 补图」，选一张本地图就贴上；「导出我补的图」可以打包发我，
  下次重建直接烤进页面。


四、更新数据（每月一次）
------------------------
数据来源是**两张**金山文档在线表：

  ① 公布版-滞销样机清理明细   https://www.kdocs.cn/l/ch7gwGTP9De4
     （只读里面的「滞销清理明细」和「样机清理明细」两个 sheet）
  ② 2026年10月价格表-LYDF-共享 https://www.kdocs.cn/l/cficbK9Drrdp
     （只读「型号价格表（只看这个）」）

两张表按型号自动合并成一张卡：①出清理价和清理库存，②出全新机报价、发货、补贴、闲鱼。

两种更新方式：

【推荐】窗口里点「↻ 从金山文档更新数据」——**一次把两个表都拉下来**
  · 该表是公开分享的，通常 20 秒内后台静默完成，你什么都不用做。
  · 第一次用（或登录过期）→ 会弹出一个「登录金山文档」窗口，
    用微信/手机扫码登录即可，**登录成功后不用点任何按钮，会自动继续**。
    登录状态会记住，以后就不用再扫了。
  · 某个表这次没拉成功，不会影响另一个，会沿用上一次的数据。

【备用】点「📂 用本地 Excel 更新」
  自己去金山文档把表下载成 xlsx，然后选这个文件传进来。
  软件会**自动认出来**你传的是哪一张表，放到对应位置。在线表登不上时用这个。


五、常见问题
------------
Q: 提示「本机缺少 Microsoft Edge WebView2 运行时」
A: 装一下就好（免费，2MB）：
   https://go.microsoft.com/fwlink/p/?LinkId=2124703
   安装包里已经带了离线引导器，正常情况下不会看到这个提示。

Q: 更新时提示「登录窗口被关闭，已取消更新」
A: 重新点一次「从金山文档更新数据」即可。

Q: 「标记已发布」和「我的定价」会丢吗？
A: 不会，存在本机（跟着 Windows 用户走）。但**换电脑、或用浏览器打开网页版**是
   不共享的；网页版和软件版的记录也各存各的。

Q: 双击了没反应？
A: 软件是单实例的——已经在跑就不会开第二个，而是把原来那个窗口叫到前面来。
   如果找不到窗口，看一眼任务栏，或在任务管理器结束 ModelLookup.exe 再打开。

Q: 软件装在哪？怎么卸载？
A: 装在 %LOCALAPPDATA%\Programs\ModelLookup（只装给当前用户，不需要管理员）。
   卸载走「设置 → 应用 → 型号查询」，或开始菜单里的「卸载 型号查询」。

Q: 数据准不准？
A: 价格/库存全部取自供应商在线表，仅供查询参考，实际以 ERP 实时数据为准。

· 数据源从 1 张表变 2 张表（多了 LYDF 价格表），合并后 **977 个型号**，
  机图覆盖率 76.3% → 86.1%（841/977）。
· 卡片上补全：价格含税 / 滞销价格 / 样机价格、正品可用库存 / 样机可用库存、
  发货区域 / 货来源、补贴 69 码 / 补贴最高价格 / 补贴可赚 / 用户补贴金额、
  闲鱼商品 ID / 闲鱼价格 / 利润。

  表里另外写了备注的原文写清楚并上色（见上面第二节）。

· **每张卡片都有「闲鱼定价」计算器**（以前没有清理价的型号会整行不见，现在都在，
  成本可选 滞销清理价 / 样机清理价 / 滞销价格 / 样机价格 / 价格含税）。
